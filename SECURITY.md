# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.1.x   | :white_check_mark: |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

We take cybersecurity vulnerabilities seriously. If you discover a security flaw or vulnerability within PhishEye:

1. **Do not** disclose the vulnerability publicly in GitHub issues or discussions.
2. Email full technical details and proof-of-concept steps directly to **`bakasakuta33@gmail.com`**.
3. We will acknowledge receipt of your report within 48 hours and work on a remediation patch.
4. Once verified and resolved, an advisory will be published and credit will be acknowledged in our release notes.
