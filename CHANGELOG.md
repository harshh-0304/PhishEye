# Changelog

All notable changes to PhishEye are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Pip-installable package via `pyproject.toml` / `setup.py` with a `phisheye` CLI entry point.
- Containerized deployment via `Dockerfile` and `docker-compose.yml`.
- Continuous integration workflow for tests and code quality.
- Automated security audit workflow (Bandit + Safety).
- Enhanced model evaluation with cross-validation and classification metrics.
- Project tooling: `.editorconfig`, `.gitattributes`, `Makefile`, and Dependabot.
- `CONTRIBUTING.md`, `SECURITY.md`, and MIT `LICENSE`.

### Changed
- Expanded README with architecture, CLI guide, API documentation, and test badges.
